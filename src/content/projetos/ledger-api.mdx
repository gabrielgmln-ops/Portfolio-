## Teste de fumaça

Contra a API publicada no Render:

- Saúde: `status=UP`, banco `UP`, actuator `UP`; Swagger UI responde HTTP 200.
- Idempotência: a mesma transferência enviada 2 vezes com a mesma chave retornou HTTP 201 nas duas, a segunda marcada `repetida=true`; não duplicou.
- Saldo insuficiente: transferir R$ 500 com saldo de R$ 100 foi bloqueado com HTTP 422.
- Saldos finais: A = 75,00 e B = 25,00 (o valor saiu uma única vez); extrato de A com 2 lançamentos.

## Teste de concorrência

Medido em 21/10/2026 com `mvnw verify`, contra PostgreSQL 16 real via Testcontainers (a mesma suíte roda na CI a cada push). Não foi executado contra a API publicada.

- 10 contas com R$ 1.000,00 cada (total R$ 10.000,00); 1.000 transferências simultâneas em 50 threads, em sentidos cruzados, com valores aleatórios entre R$ 0,01 e R$ 300,00.
- A soma das contas continuou em R$ 10.000,00: 0 centavos criados ou perdidos.
- Nenhuma conta ficou negativa; a soma de todos os lançamentos é exatamente R$ 0,00 (partidas dobradas).
- Todas as transferências terminaram como concluída ou recusada por saldo insuficiente, sem erro inesperado e sem deadlock. Parte é recusada de propósito; o teste não registra quantas passaram em cada execução.
- Complementar: 500 saques simultâneos de R$ 1,00 numa conta com R$ 100,00 resultaram em exatamente 100 aceitos e saldo final R$ 0,00.
- Suíte: 33 testes, 0 falhas; cobertura de linhas 94,7% (270 de 285, JaCoCo).
