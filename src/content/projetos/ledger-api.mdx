## Resultado medido

Teste de fumaça contra a API publicada:

- Saúde: `status=UP`, banco `UP`, actuator `UP`; Swagger UI responde HTTP 200.
- Idempotência: a mesma transferência enviada 2 vezes com a mesma chave retornou HTTP 201 nas duas, a segunda marcada `repetida=true`; não duplicou.
- Saldo insuficiente: transferir R$ 500 com saldo de R$ 100 foi bloqueado com HTTP 422.
- Saldos finais: A = 75,00 e B = 25,00 (o valor saiu uma única vez); extrato de A com 2 lançamentos.

## Critério de prova

1.000 transferências simultâneas sem perder um centavo. Ainda não medido.
